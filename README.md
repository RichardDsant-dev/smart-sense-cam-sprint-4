# Challenge – Smart Sense Cam (Sprint 04)

Equipe TaskFlow — FIAP 2026

Landing page da Sprint 03 integrada ao React (Vite).

## Como rodar

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # build de produção (pasta dist)
npm run preview  # visualizar o build
```

## Estrutura

```
src/
  components/   Header, Hero, Solucao, PublicoAlvo, Galeria, Equipe, Footer, Card, SectionTitle
  data/         content.js (textos, imagens e membros)
  styles/       sprint.css (estilos da Sprint 03)
  assets/       imagens
```
